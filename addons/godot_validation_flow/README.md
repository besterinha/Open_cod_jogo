# Godot Validation Flow

Editor validation workbench for Godot 4.3+.

Full documentation: https://indieshade.github.io/godot-validation-flow/

Repository: https://github.com/indieshade/godot-validation-flow

## Install

1. Enable this plugin under **Project → Project Settings → Plugins**.
2. Open the **Validation** bottom panel (or press **Ctrl+Alt+D**).
